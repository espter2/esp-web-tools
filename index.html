SHL Controller Flasher

Internal tool

Firmware installation

Status
Ready
Firmware profiles
Standard 2.0.6 / Landscape 2.0.7 / Stock WLED 0.14.0 (4×200 SK6812 RGBW)
Target
SHL ESP32 controller
Flash size
16 MB physical (Stock WLED uses a 4 MB layout)

Procedure

  1. Connect the powered USB hub and up to 16 controllers.
  2. Select Add controller once for each COM port. Browser permission is remembered for future sessions.
  3. Confirm that the expected controller count is shown.
  4. Select Flash all.
  5. Keep the hub connected until every controller shows Complete.

If initialization fails, close other programs using the COM port. Retry while holding the controller’s BOOT button, then release it when writing begins.
