Status

Target
SHL ESP32 controller
Flash size
16 MB
Open this tool in Google Chrome or Microsoft Edge on Windows. Open this tool from its secure Cloudflare address.

Procedure

  1. Connect one controller with a data-capable USB cable.
  2. Select Connect controller.
  3. Choose the controller’s COM port from the browser prompt.
  4. Select Install and wait for 100% completion.
  5. Disconnect the finished controller and connect the next one.

If initialization fails, close other programs using the COM port. Retry while holding the controller’s BOOT button, then release it when writing begins.
