SHL Controller Tools

Install controller firmware in your browser.

No VS Code, PlatformIO, or command line required. Connect the controller to this Windows PC with USB and follow the installer.

Production firmware SHL 2.0.4

Ready to install

This installs the production firmware for a 16 MB SHL ESP32 controller. Disconnect any other serial devices before continuing.

This installer needs Google Chrome or Microsoft Edge on Windows. Open this installer from its secure HTTPS address, not as a file downloaded to the PC.
1
Connect USB Use a data-capable USB cable and wait for Windows to recognize the controller.
2
Choose the port Click Install firmware and select the USB serial or COM device in the browser prompt.
3
Install and restart Choose Install. Keep USB connected until the progress reaches 100% and the controller restarts.

Connection trouble? Close any program using the COM port. If initialization still fails, hold the controller’s BOOT button while starting the installer, then release it when writing begins.
